## 后续维护

在 `index.html` 中搜索 `id="schedule-data"`。这个 JSON 是数据区，紧接其后的脚本是页面逻辑。

- `courses` 每行：`[课程号, 名称, 教师, 学分, 类别, 班号]`。
- `events` 每行：`[日期, 课程下标, 开始时间, 结束时间, 教室, 第几次课, 备注, 教学周]`。课程下标从 0 开始。
- `englishDates` 是英语课尚未补齐时间地点的日期。
- `holidays` 是原表标注的假期。

改动后保持 events 按日期、开始时间排序。日期使用 `YYYY-MM-DD`，时间使用 24 小时制 `HH:mm`。如果补充英语课，应同时调整 `englishDates` 的待确认提醒与页面中相关说明。

网页不会自动登录或同步选课系统。临时调课以学院及教师通知为准。
